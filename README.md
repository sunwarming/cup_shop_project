# Интернет-магазин тематических кружек и термосов

## Описание проекта
Данный проект является лабораторной работой по освоению базовых возможностей веб-фреймворка Django. Приложение представляет собой каркас будущего интернет-магазина, специализирующегося на продаже стильной и практичной посуды: термокружек, термосов и тематических кружек с уникальными принтами.

## Реализованный функционал
* Настроено виртуальное окружение и инициализирован Django-проект.
* Изменены базовые конфигурации (язык интерфейса переведен на русский, установлен часовой пояс Europe/Minsk).
* Создано изолированное приложение `shop`, отвечающее за логику магазина.
* Настроена базовая URL-структура проекта.

## Список страниц магазина
1. **Главная страница (`/`)** — приветственная страница, содержащая навигационные ссылки для перехода в другие разделы.
2. **О магазине (`/about-store/`)** — текстовая страница, кратко описывающая тему лабораторной работы и специфику продаваемых товаров.
3. **Об авторе (`/about-author/`)** — страница, содержащая информацию о создателе проекта (ФИО, группа).
