# Интернет-магазин тематических кружек и термосов (Часть 1 и 2)

## Описание проекта
Данный проект является лабораторной работой по веб-разработке на фреймворке Django. Приложение представляет собой каркас интернет-магазина, специализирующегося на продаже стильной и практичной тематической посуды: термокружек, термосов и кружек с уникальными принтами.

В рамках работы была спроектирована база данных, настроена панель администратора, реализовано автоматическое наполнение базы тестовыми данными, а также созданы веб-страницы с динамическим выводом информации из БД при помощи Django ORM.

## Использованные технологии
* Python 2026 / Django 5.x
* Django ORM (База данных SQLite3)
* Шаблонизатор Django (HTML/CSS)
* Pillow (для работы с ImageField)

## Структура Базы Данных (Модели)
1. **Категория товара (`Category`)** — хранит категории (10 уникальных категорий).
2. **Производитель (`Manufacturer`)** — бренды и страны-изготовители посуды (5 брендов).
3. **Товар (`Product`)** — содержит подробную информацию, цену, остаток на складе и внешние ключи. Добавлена валидация на неотрицательную цену и остаток.
4. **Корзина (`Cart`)** — связана связью «Один-к-одному» со встроенной моделью `User`. Имеет встроенный метод подсчета общей стоимости всех элементов.
5. **Элемент корзины (`CartItem`)** — содержит информацию о товаре в корзине и его количестве. Добавлена валидация: количество в корзине не может превышать остаток товара на складе.

## Список страниц магазина
* **Главная страница (`/`)** — приветственная страница со ссылками на разделы.
* **Каталог товаров (`/products/`)** — динамическая страница. Поддерживает:
  * Поиск товаров по названию через ORM-фильтрацию (`__icontains`).
  * Фильтрацию товаров по выбранной категории.
  * Сортировку по цене (от дешевых к дорогим и наоборот).
* **Страница товара (`/products/<id>/`)** — страница детализации конкретного товара, использующая метод `get_object_or_404`.
* **О магазине (`/about-store/`)** — plain-text страница с описанием темы.
* **Об авторе (`/about-author/`)** — plain-text страница с данными автора.

## Наполнение базы данных
База данных проекта успешно заполнена через Django Shell:
* Создано производителей: 5 шт.
* Создано категорий: 10 шт.
* Сгенерировано товаров: 34 шт.
* Создано пользователей: 5 шт. (для каждого автоматически сформирована корзина со случайным набором товаров).
